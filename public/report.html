Redovisning

Här kommer mina redovisningstexter från de olika kursmomenten i denna kursen.

kmom04

1. Förstår du hur HTML/CSS/JavaScript hänger ihop när vi utvecklar för webben? Ja, jag har bättre koll på hur HTML, CSS och Javascript samarbetar. HTML skapar strukturen på sidan, CSS bestämmer hur sidan ser ut och JavaScript gör sidan interaktiv och funktionell.

2. Känner du att du har koll på hur vi kan manipulera HTML elementen med hjälp av JavaScript? Ja, jag har lärt mig en hel del, speciellt när man skriver koden själv. Har tex lärt mig hur man kan ändra HTML-element med JavaScript, tex genom klasser, storlekar och färger, ändra och skapa nya element.

3. Hur tycker du att din kodstruktur blev över uppgiften? Jag tycker att min kodstruktur blev bra, jag tog hjälp av internet, delade upp koden i HTML, CSS och JavaScript vilket kommer att göra det tydligare och enklare att förstå. Ibland blev det fel, men jag felsökte och lärde mig en hel del, utan att göra fel kan man inte utveckla sig.

4. Vilken är din TIL för detta kmom? Min TIL var att utveckla mig inom JavaScript, alltså att man kunde manipulera en hel del med JavaScript var fantastiskt. Det var intressant med tangentbordknappar och kunna styra de inom hemsidan man själv skapade, det hade jag funderat på hur länge som helst.

kmom05

Det gick väldigt bra att lösa uppgiften, även om jag behövde felsöka några delar av koden. Jag lärde mig dessutom hur man hämtar data från JSON-filer med Fetch API och visa information för olika länder i en tabell. Det var även roligt att lära sig hur man markerar vinnaren med en fgrön bakgrund.

Man kan tydligt se fördelarna med async/await eftersom det underlättar kodläsningen och hjälper även med att hämta datan innan jag börjar använda den, ett säkert sätt ju!

Det krångligaste med denna uppgift var att man glömde lägga till vissa filer som gjorde att CSS inte fungerade, alltså glömde jag helt och hållet att koppla CSS med HTML och jag förstod inte riktigt vad som pågick! Jag behövde även rätta småfel i Javascript såsom bokstäver och tecken.

Min TIL för denna kursmoment var att lära sig om Fetch API, Async/await och lite mer om hur Javascript kan hantera en hemsida,

kmom06

Det gick helt ok att lösa uppgiften, tyckte att några delar inom JavaScript var lite jobbiga, därför fick jag felsöka och rätta till koden, men det var spännande!

Jag älskade JavaScript och tycker att det är betydligt användbart men man behöver ganska mycket tid att lära sig, tycker det är lite för mycket att lära sig ibland men det är spännande även om det är svårt. Ibland är det också svårt att hitta sina fel om man har skrivit en lång kod. Men smått och svårt, jag lär mig vid varje video och vid varje tillfälle.

Min TIL är att jag har lärt mig hur JavaScript används för att ändra HTML-element, hur man hanterar klickhändelser, och hur man kan fetcha bilder från nätet, skönt o slippa att ladda ner. Har även lärt mig hur man felsöker, console hjälper sååå mycket, vilket är skönt och felsöka om man har missat något eller om något har gått fel.
